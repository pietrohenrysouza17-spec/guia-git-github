# Introdução ao Git e GitHub para Iniciantes

## Objetivo

Este guia tem como objetivo apresentar os conceitos básicos de Git e GitHub para iniciantes, ensinando como utilizar essas ferramentas para versionar, organizar e compartilhar projetos.

Ao longo do guia, serão apresentados conceitos, comandos, exemplos e exercícios práticos para facilitar o aprendizado.

## Público-alvo

Este guia é destinado a estudantes e pessoas que estão começando a aprender programação e ainda não possuem experiência com Git e GitHub.

## Pré-requisitos

* Conhecimentos básicos de informática;
* Computador com acesso à internet;
* Git instalado no computador;
* Conta no GitHub;
* Editor de texto ou código, como o Visual Studio Code.

Não é necessário ter conhecimento prévio de Git ou GitHub.

## Estrutura

O guia está organizado nos seguintes módulos:

1. **Introdução ao Git e GitHub** — conceitos básicos e diferenças entre Git e GitHub.
2. **Conceitos fundamentais** — repositórios, commits, branches, merge e Pull Requests.
3. **Exercícios práticos** — atividades para praticar os comandos apresentados.
4. **Referências** — documentação e materiais utilizados na elaboração do guia.

Também serão apresentados exemplos práticos de utilização do Git.

## Como navegar

Comece pelo módulo **01 - Introdução** e avance pelos módulos na ordem apresentada.

A sequência recomendada é:

**Introdução → Conceitos → Exemplos → Exercícios → Referências**

Os exemplos podem ser utilizados como apoio durante a realização dos exercícios.

## Comandos básicos

Alguns dos principais comandos utilizados no Git são:

- `git init` — cria um novo repositório Git;
- `git clone` — copia um repositório existente;
- `git status` — mostra o estado dos arquivos;
- `git add` — adiciona alterações à área de preparação;
- `git commit` — registra as alterações no histórico;
- `git push` — envia os commits para o repositório remoto;
- `git pull` — busca e integra alterações do repositório remoto.
