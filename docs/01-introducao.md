# 01 - Introdução ao Git e GitHub

## O que é Git?

Git é um sistema de controle de versão distribuído. Ele permite acompanhar as alterações realizadas em um projeto ao longo do tempo.

Com o Git, é possível registrar versões do projeto, identificar alterações, recuperar versões anteriores e trabalhar em diferentes linhas de desenvolvimento.

## O que é GitHub?

GitHub é uma plataforma utilizada para hospedar repositórios Git e facilitar a colaboração entre desenvolvedores.

Enquanto o Git é a ferramenta responsável pelo controle de versão, o GitHub oferece recursos para armazenar os repositórios remotamente, compartilhar projetos e colaborar por meio de recursos como Pull Requests.

## Git x GitHub

| Git                             | GitHub                                      |
| ------------------------------- | ------------------------------------------- |
| Sistema de controle de versão   | Plataforma de hospedagem e colaboração      |
| Funciona localmente             | Utiliza repositórios remotos                |
| Registra alterações e histórico | Facilita o compartilhamento e a colaboração |
| Pode funcionar sem internet     | Normalmente utilizado conectado à internet  |

O Git pode ser utilizado sem o GitHub. Por exemplo, um projeto pode ser versionado completamente no computador usando apenas o Git.

## Controle de versão

O controle de versão permite acompanhar a evolução de um projeto.

A cada alteração importante, o desenvolvedor pode criar um commit, registrando um estado do projeto no histórico.

Isso permite saber:

* o que foi alterado;
* quando a alteração foi realizada;
* quem realizou a alteração;
* qual foi o motivo registrado no commit.

## Repositório local e remoto

O repositório local fica armazenado no computador do desenvolvedor.

O repositório remoto é armazenado em uma plataforma como o GitHub e pode ser utilizado para compartilhar o projeto e colaborar com outras pessoas.

Um projeto pode ter alterações registradas localmente e posteriormente enviadas para o repositório remoto utilizando comandos como `git push`.

Da mesma forma, alterações existentes no repositório remoto podem ser obtidas utilizando comandos como `git pull`.

## Por que utilizar Git?

O Git ajuda a:

* acompanhar a evolução de um projeto;
* organizar alterações;
* recuperar versões anteriores;
* trabalhar com branches;
* colaborar com outras pessoas;
* manter um histórico das alterações.

## Resumo

Git é responsável pelo controle de versão do projeto, enquanto o GitHub é uma plataforma que facilita o armazenamento remoto e a colaboração.

O controle de versão permite registrar alterações e acompanhar a evolução do projeto por meio do histórico de commits.
