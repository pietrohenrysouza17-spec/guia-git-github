# 04 - Referências

## Documentação oficial do Git

A documentação oficial do Git apresenta informações sobre comandos, conceitos, configuração e funcionamento do sistema de controle de versão.

**Git Documentation:**
https://git-scm.com/doc

## GitHub Docs

A documentação oficial do GitHub apresenta recursos relacionados a repositórios, branches, commits, Pull Requests, colaboração e GitHub Flow.

**GitHub Docs:**
https://docs.github.com/

## Git Book

O Pro Git é um livro gratuito que apresenta os principais conceitos e recursos do Git, desde os fundamentos até recursos mais avançados.

**Pro Git:**
https://git-scm.com/book/en/v2

## Conventional Commits

A especificação Conventional Commits apresenta uma convenção para estruturar mensagens de commit de forma padronizada.

**Conventional Commits:**
https://www.conventionalcommits.org/

## Materiais utilizados no projeto

Além da documentação oficial, foram utilizados os materiais didáticos disponibilizados na disciplina para estudar conceitos como:

* Controle de versão;
* Repositórios;
* Commits;
* Staging Area;
* Branches;
* Merge;
* Conflitos;
* Pull Requests;
* GitHub Flow;
* Comandos básicos do Git.

## Observação

As referências foram utilizadas como apoio para a elaboração dos conteúdos, exemplos e exercícios apresentados neste guia.
